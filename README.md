# ical

Calendar feeds generated by GitHub Actions.

## UFC calendar

Subscribe in Apple Calendar using:

https://ndrwstn.github.io/ical/ufc.ics

The UFC feed is generated by `npm run generate:ufc`. GitHub Actions runs it every four hours and can also be started manually from the Actions tab.

The generator scrapes UFC.com for announced events, separates early prelims/prelims/main card fights, includes rankings and divisions, uses the requested naming format, adds venue addresses, and sets an alert at event start.

## GitHub Pages setup

In repository **Settings → Pages**, set the source to **GitHub Actions**. The workflow publishes the `public` directory.

The default branch should be **master**.
